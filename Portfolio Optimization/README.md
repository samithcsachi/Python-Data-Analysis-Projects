# Portfolio Optimization 

In this Project we doing the basic Analysis of Market Performance. Have done Exploratory analysis and Basic visualization. 


# Dataset

Dataset includes details of the top 5 stocks in Nasdaq over the period of 1 year. 

The columns in this dataset are:

- Date
- Ticker
- Adj Close
- Close	
- High	
- Low	
- Open	
- Volume
